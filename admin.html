Brancher les graphiques

Les chiffres viennent de GoatCounter. Pour les afficher ici en graphiques, il faut une clé API GoatCounter en lecture seule :

  1. sur launtzero.goatcounter.com, clique sur ton nom en haut, puis API ;
  2. crée une clé, coche seulement « Read statistics », enregistre ;
  3. copie la clé et colle-la ci-dessous. Elle reste dans ce navigateur seulement.
